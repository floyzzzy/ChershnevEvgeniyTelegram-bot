Данная работа посвящена разработке Телеграм бота (прототипа), предназначенного для рассмотрения, как устроены онлайн сервисы доставки. При помощи этого бота, можно ознакомиться с тем, как же все-таки работают любимые услуги. Разработка такого бота позволит упростить и ускорить процесс создание подобных ботов для онлайн бизнеса и не только.
